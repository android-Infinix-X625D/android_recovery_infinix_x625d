# Infinix HOT 7 Pro (*X625D*)

Recovery device tree for Infinix Hot 7 Pro (OrangeFox)

## Device specifications

Device                  | Infinix X625D / HOT 7 PRO (H623L)
-----------------------:|:-----------------------------------------
SoC                     | MediaTek MT6765 (12nm)
CPU                     | Octa-core 8x Cortex-A53 (up to 2.35 GHz)
GPU                     | PowerVR GE8320
Memory                  | 6 GB RAM
Storage                 | 64 GB (eMMC 5.1)
Storage expansion       | microSDXC (dedicated slot)
Shipped Android Version | 9.0
Battery                 | Non-removable 4000 mAh
Display                 | 6.19 inches, IPS LCD, 720 x 1500 px, 60Hz
Camera                  | 13 MP AF + aux (back); dual 13 MP + 2 MP depth (front)
Released                | 2019, March (165 g, 8 mm)


## Features

- [X] ADB

- [X] Vibrator

- [X] Realtime battery / charge status
